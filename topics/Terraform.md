# Terraform Interview Questions

This section contains common Terraform interview questions and scenarios.

## Common Questions

* **Explain the Terraform state file (`terraform.tfstate`). Why is it important and how should it be managed securely?**
* **What is the difference between `terraform plan` and `terraform apply`?**
* **How do you handle secrets and sensitive data in Terraform?**
* **Explain Terraform Workspaces. When would you use them over separate directories?**
* **How do you write a custom Terraform module and use it across multiple environments?**
* **What are `null_resource` and `local-exec` provisioners used for?**

Please follow the guidelines in our main [CONTRIBUTING.md](../CONTRIBUTING.md) to add new questions or tips here.
