# Docker & Kubernetes Interview Questions

This section covers containerization and container orchestration.

## Docker Questions
* **Explain the difference between a Docker image and a Docker container.**
* **What is a multi-stage Docker build and why would you use it?**
* **How can you reduce the size of a Docker image?**

## Kubernetes (K8s) Questions
* **Explain the architecture of a Kubernetes cluster (Control Plane vs Worker Nodes).**
* **What is a Pod, and how is it different from a Node?**
* **Explain the difference between a Deployment and a StatefulSet.**
* **How do you securely pass secrets to a Kubernetes application (e.g., using Secrets vs external secret operators)?**
* **What is an Ingress Controller? How does it route traffic to your services?**
